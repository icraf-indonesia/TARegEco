# Diagnostik: Cek Kecocokan Nama Sektor di io_changes vs Baseline

Diagnostik: Cek Kecocokan Nama Sektor di io_changes vs Baseline

## Usage

``` r
check_io_changes(io_changes, sektor_names, Z)
```

## Arguments

- io_changes:

  Data frame. Isi file A3.

- sektor_names:

  Character vector. Nama sektor baseline.

- Z:

  Numeric matrix. Matriks transaksi antara baseline.

## Value

Invisible NULL. Memunculkan warning jika ada masalah.
